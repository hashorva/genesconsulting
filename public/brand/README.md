# Genes Consulting logo

Vector files, regenerated by `python3 scripts/logo/build_logo.py <NotoSans-Bold.woff> <NotoSans-Light.woff>` (Noto Sans 700 and 300, text converted to paths, so no font is needed to display them).

| File | Use |
| --- | --- |
| `mark-dark.svg` / `mark-light.svg` | The arcs alone, for a dark or a light background |
| `logo-dark.svg` / `logo-light.svg` | Mark plus GENES / CONSULTING, for a dark or a light background |
| `../favicon.svg`, `../favicon.ico`, `../apple-touch-icon.png`, `../icon-192.png`, `../icon-512.png` | Favicon and app icons (mark on `sky-950`) |

Colors are Tailwind v4 default palette values only: `sky-400`, `sky-500`, `sky-600`, `sky-900`, `sky-950`, `slate-300`, `slate-600`, `white`. The mark is redrawn from the geometry of the client's logo (four concentric quarter rings, ratio 4:3:2:1), not auto-traced, so the curves are exact. The light variant uses one step darker blues so the arcs keep contrast on white.

Swap into the site: replace the lucide `Rss` placeholder with `logo-light.svg` / `logo-dark.svg` (or inline the mark) in the header and footer, and point the favicon links at `/favicon.svg`, `/favicon.ico` and `/apple-touch-icon.png`. PNG previews are in `docs/design/logo/`.
