# Genes Consulting logo

Vector files, regenerated by `python3 scripts/logo/build_logo.py <NotoSans-Bold.woff> <NotoSans-Light.woff>` (Noto Sans 700 and 300, text converted to paths, so no font is needed to display them).

| File | Use |
| --- | --- |
| `mark-dark.svg` / `mark-light.svg` | The arcs alone, for a dark or a light background |
| `logo-dark.svg` / `logo-light.svg` | Mark plus GENES / CONSULTING, for a dark or a light background |
| `../favicon.svg`, `../favicon.ico`, `../apple-touch-icon.png`, `../icon-192.png`, `../icon-512.png` | Favicon and app icons (mark on `sky-950`) |

Colors are Tailwind v4 default palette values only: `sky-400`, `sky-500`, `sky-600`, `sky-900`, `sky-950`, `yellow-600` (gold accent), `slate-300`, `slate-600`, `white`. The light variant uses one step darker blues so the arcs keep contrast on white.

The mark is drawn on a 5x5 grid (1 cell = 100 units), not auto-traced, so the curves are exact: a C arc and a G arc (0.85 cell thick, 0.3 gap), both centred on the bottom-right corner, plus the G's bar and terminal in gold (a quarter disc of radius 2 cells with a 0.85 cell square notch, so the bar line meets the terminal corner on the square's diagonal). The geometry constants are at the top of `scripts/logo/build_logo.py`.

Site wiring: `SiteLogo.astro` renders them in the header and footer (light/dark swap with `dark:`), and `layouts/Base.astro` links the favicons. A logo uploaded in EmDash site settings still overrides the header image.
